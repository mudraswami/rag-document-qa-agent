# RAG Document Q&A Agent

A practical Retrieval-Augmented Generation (RAG) project for answering questions from documents using document retrieval and an LLM.

## Project Overview

This project demonstrates how a RAG pipeline can retrieve relevant information from documents and use that context to generate answers with an LLM.

## Planned Workflow

Document → Chunking → Embeddings → Vector Store → Retrieval → LLM → Answer

## Technologies

- Python
- LangChain
- FAISS
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Gradio
- LangServe

## Project Goals

- Process and split documents into smaller chunks
- Generate embeddings for document content
- Store and retrieve relevant information
- Pass retrieved context to an LLM
- Generate context-aware answers
- Provide a simple interface for asking questions
